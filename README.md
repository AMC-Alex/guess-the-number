## Guess the Number

A simple number guessing game built with HTML, CSS and JavaScript.

The player must guess a randomly generated number between 1 and 100, with a limited number of attempts.

## Features

- Random number generation between 1 and 100.
- Five attempts to guess the correct number.
- Feedback indicating whether the guess is too high or too low.
- Input validation.
- Win and game-over messages.
- Restart the game.

## Technologies

- HTML5
- CSS3
- JavaScript

- How to Play
- Enter a number between 1 and 100.
- Submit your guess.
- Read the feedback to find out whether the secret number is higher or lower.
- Keep guessing until you find the correct number or run out of attempts.
- Start a new game and try again.

You have 5 attempts to guess the number.
